# 双语文档 —— 英文为源，中文镜像

本仓库里每一份面向人阅读的文档都存在两份：一份英文、一份中文。英文是源头——代码、ADR 和发版说明都以它为基准——中文文件是它的镜像。**两侧必须在同一次提交里一起改动。**

## 配对规则

一份文档的中文版就在它旁边，把 `.md` 换成 `.zh.md`：

| 英文 | 中文 |
|---|---|
| `README.md` | `README.zh.md` |
| `CONTEXT.md` | `CONTEXT.zh.md` |
| `docs/guides/quickstart.md` | `docs/guides/quickstart.zh.md` |
| `docs/adr/0019-mesh-transport-security.md` | `docs/adr/0019-mesh-transport-security.zh.md` |
| `examples/cf-serverless-node/VERIFICATION.md` | `examples/cf-serverless-node/VERIFICATION.zh.md` |

其余什么都不变：没有 `zh/` 目录树、没有重命名目录、没有按语言分叉的构建步骤。reviewer 在一次 diff 里就能看到这一对。

## 共享的东西，永不复制

**资源。** 图片、SVG 和可交互的 HTML 图只存在一份，位于 `docs/guides/assets/` 下。`.zh.md` 文件引用与英文文件相同的路径——绝不复制，绝不翻译图本身。两侧是同一张图。

**代码。** 围栏代码块、行内命令、flag、文件路径、配置键、标识符、版本号和 URL 保持字节一致。翻译一条命令就把它变成错的；翻译一个路径就把它弄坏。

**结构。** 标题、段落、列表项、表格和代码围栏一一对应，这样读者可以 diff 两份文件，译者也能看出哪里动了。标题*文本*被翻译；标题*层级与顺序*不翻译。

## 翻译什么

正文、标题、表头与表格单元格里的正文、图注，以及告示式引用块里的文字。术语遵循 `CONTEXT.md`——词汇表里的词（Mesh、Node、Board、Card、Marker、Handoff……）即使出现在中文句子里也保持英文拼写，因为它们在本项目里是名字，不是普通单词。

## 链接

- 指向另一份文档的相对链接指向那份文档的中文版：英文里的 `[Quickstart](quickstart.md)` 在中文里是 `[快速开始](quickstart.zh.md)`。
- 目标没有中文版的链接（skill 文件、源码文件、目录列表）保持原样。
- 页内锚点（`#some-section`）在中文文件里可以省略——标题被翻译后 slug 会变，指向页面的链接好过一个死片段。
- 外部 URL、徽章和 raw 文件安装链接保持不变。

## 出处行

每个中文文件都以一行开头，指明它的英文来源，这样落到中文页面的读者总能找到权威文本：

```markdown
> 中文版 · 英文原文：[README.md](README.md)
```

`README.zh.md` 在英文 README 链接 YouTube 的位置改用简介视频的 B 站版本
（<https://www.bilibili.com/video/BV1oQWc6fEn9>）；该节其余内容完全相同，包括共享的架构图。

## 范围

成对维护：`README.md`、`CONTEXT.md`、`CONTRIBUTING.md`、`AGENTS.md`、`docs/` 下的一切（guides、ADR、dev 笔记、发版指南、milestones），以及 `examples/` 与 `promo/` 的 README，还有 `docs/i18n.md` 自身。

有意不配对：

| 路径 | 原因 |
|---|---|
| `skills/**` | 随包发布、由模型阅读的提示词材料，会被安装到其他宿主。翻译副本会成为第二个行为事实来源。 |
| `.agents/skills/**` | 本仓库的 agent 工具；它们是指令，不是文档。 |
| `.pi/**`、`.pig/**` | 本地工作状态，不是文档。 |

## 强制手段

`src/docs-pairs.test.ts` 在 `npm test` 中运行，遇到以下情况即失败：

- 有英文文档却没有对应的 `.zh.md`（或有孤儿中文文件）；
- 结构漂移——标题数、围栏代码块数、空行分隔的块数或图片数不一致；
- 中文文件的相对文档链接没有指向 `.zh.md` 对应文件，或链接集合与英文文件不一致；
- 中文文件缺少出处行。

这个测试判断不了翻译质量。**改了英文文档却没有同步改中文版，即使测试通过也是 review 失败**——测试只能抓到结构的那一半。
