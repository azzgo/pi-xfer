# Bilingual documentation — English canonical, Chinese mirrored

Every document in this repository that is meant to be read by a human exists
twice: once in English and once in Chinese. English is canonical — it is what
the code, the ADRs and the release notes are written against — and the Chinese
file mirrors it. **Both sides move together, in the same commit.**

## The pairing rule

The Chinese counterpart of a document lives next to it, with `.zh.md` in place
of `.md`:

| English | Chinese |
|---|---|
| `README.md` | `README.zh.md` |
| `CONTEXT.md` | `CONTEXT.zh.md` |
| `docs/guides/quickstart.md` | `docs/guides/quickstart.zh.md` |
| `docs/adr/0019-mesh-transport-security.md` | `docs/adr/0019-mesh-transport-security.zh.md` |
| `examples/cf-serverless-node/VERIFICATION.md` | `examples/cf-serverless-node/VERIFICATION.zh.md` |

Nothing else changes: no `zh/` tree, no renamed directories, no per-language
build step. A reviewer sees the pair in one diff.

## What is shared, and never duplicated

**Assets.** Images, SVGs and interactive HTML diagrams live once, under
`docs/guides/assets/`. A `.zh.md` file references the same path the English file
does — never a copy, never a translated diagram. The picture is the same picture
on both sides.

**Code.** Fenced code blocks, inline commands, flags, file paths, config keys,
identifiers, version numbers and URLs stay byte-identical. Translating a command
makes it wrong; translating a path breaks it.

**Structure.** Headings, paragraphs, list items, tables and code fences line up
one-for-one, so a reader can diff the two files and a translator can see what
moved. Heading *text* is translated; heading *level and order* are not.

## What is translated

Prose, headings, table headers and cell prose, captions, and the text inside
admonition-style block quotes. Vocabulary follows `CONTEXT.md` — the glossary
terms (Mesh, Node, Board, Card, Marker, Handoff, …) keep their English spelling
even inside Chinese sentences, because they are names in this project, not
ordinary words.

## Links

- A relative link to another document points at that document's Chinese
  counterpart: `[Quickstart](quickstart.md)` in English becomes
  `[快速开始](quickstart.zh.md)` in Chinese.
- A link whose target has no Chinese counterpart (a skill file, a source file, a
  directory listing) stays exactly as it is.
- Intra-document anchors (`#some-section`) may be dropped in the Chinese file —
  heading slugs differ once the heading is translated, and a link to the page is
  better than a dead fragment.
- External URLs, badges and raw-file install links are unchanged.

## Provenance line

Every Chinese file opens with one line naming its English source, so a reader
who lands on the Chinese page can always find the canonical text:

```markdown
> 中文版 · 英文原文：[README.md](README.md)
```

`README.zh.md` uses the Bilibili cut of the intro video
(<https://www.bilibili.com/video/BV1oQWc6fEn9>) where the English README links
YouTube; everything else in that section is the same, including the shared
architecture image.

## Scope

Paired: `README.md`, `CONTEXT.md`, `CONTRIBUTING.md`, `AGENTS.md`, everything
under `docs/` (guides, ADRs, dev notes, release guide, milestones), the
`examples/` and `promo/` READMEs, and `docs/i18n.md` itself.

Not paired, on purpose:

| Path | Why |
|---|---|
| `skills/**` | Shipped prompt material read by a model, installed into other hosts. A translated copy would be a second behavioural source of truth. |
| `.agents/skills/**` | Agent tooling for this repository; instructions, not documentation. |
| `.pi/**`, `.pig/**` | Local working state, not documentation. |

## Enforcement

`src/docs-pairs.test.ts` runs in `npm test` and fails on:

- an English document with no `.zh.md` counterpart (or an orphan Chinese file);
- structural drift — a different number of headings, fenced code blocks,
  blank-line-separated blocks, or images;
- a Chinese file whose relative document links do not point at `.zh.md`
  counterparts, or whose linked set differs from the English file's;
- a Chinese file with no provenance line.

The test cannot judge translation quality. **Changing an English document
without changing its Chinese counterpart is a review failure even when the test
passes** — the test only catches the structural half.
